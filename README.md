Recycled aggregate concrete (RAC) offers an environmentally beneficial alternative to conven-tional concrete by reducing construction waste and the consumption of natural aggregates. How-ever, variability in recycled aggregate quality, residual mortar content, and mixture composition produces complex nonlinear relationships that limit the reliability of conventional empirical models. This study proposes MLRAC, an integrated machine learning framework for predicting RAC compressive strength and workability. The framework combines minimum redundancy maximum relevance feature selection, Chaos Game Optimizer-based hyperparameter optimiza-tion, and an ensemble of Gradient Boosting Machine, Support Vector Regression, and TabNet models. Two independently sampled datasets, each containing 210 experimentally tested RAC records, were used to develop and evaluate separate models for compressive strength and slump. Model performance was assessed using the coefficient of determination, root mean square error, mean absolute error, Variance Accounted For, and A20 index. On the independent testing sub-sets, MLRAC achieved an R² of 0.98, RMSE of 2.30 MPa, and MAE of 1.95 MPa for compres-sive strength prediction. For slump prediction, it achieved an R² of 0.97, RMSE of 5.60 mm, and MAE of 4.40 mm. The A20 index reached 99% for both prediction tasks, indicating that nearly all predictions were within the predefined engineering acceptance range. Bootstrap analysis fur-ther demonstrated stable performance with narrow confidence intervals for the principal evalua-tion metrics. These findings show that combining redundancy-aware feature selection, comple-mentary learning algorithms, and chaos-based optimization can improve the accuracy and stabil-ity of RAC property prediction. Within the ranges represented by the datasets, MLRAC can sup-port preliminary mixture screening, reduce unnecessary trial mixtures, and facilitate the perfor-mance-based use of recycled aggregates. The framework should nevertheless be externally vali-dated before application to materials and mixture proportions outside the investigated data do-main.


Keywords: Recycled aggregate concrete; Compressive strength prediction; Slump prediction; Hybrid machine learning; Interpretable ensemble learning; mRMR feature selection; Chaos Game Optimizer; Uncertainty quantification
